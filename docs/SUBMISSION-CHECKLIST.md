# Submission Checklist — YouCam API Skin AI & Apparel VTO Hackathon

Everything the official page requires, and where it lives in this repo.

## What to Build

- [x] **Integrates ≥1 YouCam API** — Glow integrates **three** (Skin Analysis, Skin Tone, Fitzpatrick); see `src/lib/youcam.ts` and the API table in [README.md](../README.md)
- [x] **Working web prototype, clear consumer/retail value** — live at https://yashwanth07-debug.github.io/glow-skin/ (demo mode works with zero setup)
- [x] **Not a surface-level wrapper** — routine rules engine, uncertainty engine, self-correcting capture pipeline, adaptive polling; 26 unit tests

## What to Submit

- [x] **Code repository URL** — https://github.com/yashwanth07-debug/glow-skin (public, [MIT license](../LICENSE), all source + runnable instructions in README)
- [x] **Text description with features + consumer/retail value** — paste-ready in [../DEVPOST.md](../DEVPOST.md)
- [x] **Screenshots of the project** — [screenshots/](.) (10 shots: landing, capture, analyzing, report, region view, routine, progress, share card, dark mode, desktop) — upload these to the Devpost gallery
- [ ] **Demo video (1–3 min)** — script + official constraints in [../DEVPOST.md](../DEVPOST.md#-demo-video-script-1–3-min-requirement-checklist)
  - [ ] ≤ 3 minutes (judges not required to watch longer)
  - [ ] Explains which YouCam APIs are used (script does this at 0:40)
  - [ ] Shows the app running on a real device (record on a phone)
  - [ ] Public YouTube (preferred) / Vimeo / Youku; link added to the submission form
  - [ ] No third-party trademarks, no copyrighted music
- [ ] **Agree to exit interview if chosen as a winner** (accept on submission form)
- [ ] **Agree to be included in a blog article** (accept on submission form)

## Before you hit submit

1. Record the video per the script → upload → get the link.
2. Confirm the repo stays **public** while judging is active (or if flipping private, share it with `contact_event@PerfectCorp.com` per the rules).
3. Update the «TODO» fields in DEVPOST.md (team name, video URL).
4. Keep some API units in reserve in case judges test the live demo.
